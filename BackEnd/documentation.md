# fastApi
es para crear el framework web para la API REST.

# uvicorn[standard]	
El servidor ASGI que ejecuta FastAPI con soporte para recarga en tiempo real (hot-reload).

# sqlalchemy
El ORM que te permite interactuar con PostgreSQL mediante clases de Python en lugar de SQL puro.

# psycopg2-binary	
El driver nativo para que Python pueda comunicarse con PostgreSQL.

# pydantic	
La librería de FastAPI para validar y tipar las entradas/salidas de los JSON.

# pydantic-settings	
Permite gestionar variables de entorno (.env) de forma segura y tipada.

# cryptography / passlib
Para encriptar o hashear de forma segura las contraseñas generadas antes de guardarlas en la base de datos.
